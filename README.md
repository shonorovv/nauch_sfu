# Диффузия нейромедиаторов в синапсе

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)
![GPU](https://img.shields.io/badge/GPU-CuPy%2014.1-green?logo=nvidia&logoColor=white)
![CUDA](https://img.shields.io/badge/CUDA-12.x-brightgreen?logo=nvidia)
![License](https://img.shields.io/badge/Лицензия-учебная-lightgrey)

Дипломный проект (СФУ, 2026). Численное решение уравнения Фоккера-Планка для моделирования диффузии и дрейфа нейромедиаторов в радиальной геометрии синапса (сферической/цилиндрической). Метод: неявная конечно-разностная схема с апвинд-аппроксимацией. GPU-ускорение через CuPy — числитель LU-разложения полностью на видеокарте.

---

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install numpy scipy matplotlib
```

Если есть NVIDIA GPU (рекомендуется) — запустить установщик CuPy:

```
Двойной клик на _run_install.bat
```

Это автоматически определит версию CUDA и установит нужный пакет (`cupy-cuda12x` или `cupy-cuda11x`).

### 2. Запуск

```bash
python main.py
```

Результаты сохраняются в папку `результаты_моделирования/`.

## Настройка параметров

Все параметры модели — в файле **`config.py`**. Самые важные:

### Геометрия синапса

| Параметр | По умолчанию | Описание |
|---|---|---|
| `a` | 200 нм | Внутренняя граница синапса |
| `b` | 400 нм | Внешняя граница синапса |
| `max_r` | 1000 нм | Размер расчётной области |

### Коэффициенты диффузии

| Параметр | По умолчанию | Описание |
|---|---|---|
| `D_cleft` | 400 нм²/мкс | Диффузия внутри синапса |
| `D_pm` | 150 нм²/мкс | Диффузия снаружи |

### Временная сетка

| Параметр | По умолчанию | Описание |
|---|---|---|
| `dt` | 0.05 мкс | Шаг по времени |
| `dr` | 0.05 нм | Шаг по пространству |
| `t_max` | 10 000 мкс | Время моделирования |

### Дрейф (Omega)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `Omega_cleft` | 0.05 | Дрейф внутри синапса |
| `Omega_pm` | 0.15 | Дрейф снаружи (= 3 × Omega_cleft) |

Чтобы **отключить дрейф**: `Omega_cleft = 0.0; Omega_pm = 0.0`

### Отбор (uptake) и физическая интерпретация массы

| Параметр | По умолчанию | Описание |
|---|---|---|
| `normalization_mode` | `"probability"` | `"probability"` = p(r,t) — вероятность одной частицы, масса принудительно нормируется к 1 на каждом шаге; `"concentration"` = c(r,t) — концентрация вещества, ренормировка отключена, масса меняется только через границу, отбор и импульсы |
| `k_cleft`, `k_pm` | `0.0` | Коэффициент отбора (uptake) k(r), 1/мкс — слагаемое `-k(r)*c` в уравнении переноса; 0 = отбора нет |

Два режима нормировки нельзя смешивать в одной интерпретации результатов — см. комментарий в `config.py`.

### Импульсы

| Параметр | По умолчанию | Описание |
|---|---|---|
| `num_pulses` | 50 | Количество импульсов (0 = без импульсов) |
| `pulse_amount` | 5.0 | Доля вероятности, добавляемая каждым импульсом |
| `pulse_sigma_nm` | 35 нм | Ширина гауссова импульса |

### GPU / CPU

| Параметр | По умолчанию | Описание |
|---|---|---|
| `use_gpu` | `True` | `True` = GPU (CuPy), `False` = CPU (scipy) |
| `max_saved_frames` | 2000 | Максимум хранимых кадров p(r,t) в памяти |

## Отключение отдельных режимов

```python
# Без импульсов
num_pulses = 0

# Без дрейфа
Omega_cleft = 0.0
Omega_pm = 0.0

# Только CPU (если нет GPU)
use_gpu = False

# Без анимации (быстрее)
enable_animation = False

# Без экспорта файлов
export_figures = False
export_data = False

# Цилиндрическая геометрия (по умолчанию — сферическая)
geometry_mode = "cylindrical"
```

## Тесты / валидация

Минимальный блок валидации решателя (`tests/test_validation.py`, без внешних
зависимостей — только `unittest` из стандартной библиотеки):

- сравнение с полуаналитическим результатом для чистой диффузии (без дрейфа
  и импульсов): рост E[r²](t) должен соответствовать точному тождеству
  d/dt E[r²] = 2·d·D (d — размерность геометрии, отражающая граница);
- сохранение массы без принудительной ренормировки (`normalization_mode =
  "concentration"`, постоянный D, нулевой Omega, no-flux граница);
- неотрицательность p(r,t);
- сеточная сходимость при измельчении (dr, dt) → (dr/2, dt/2) → (dr/4, dt/4);
- регрессионные проверки на замечания руководителя: `build_omega_case_table`
  и детектор инверсии по массе области, а не по максимуму плотности.

Запуск:

```bash
python -m unittest tests.test_validation -v
```

## Верификация на экспериментальных данных (добавлено 09.10.2026)

Сравнение модели с литературой в абсолютных единицах (мкМ):

```bash
python -m scenarios.verification              # литературные D, отбор EAAT, без дрейфа
python -m scenarios.verification --compare    # + D из курсовой
python -m scenarios.verification --scan       # перебор D_cleft x D_pm, функция потерь
python -m scenarios.verification --no-uptake  # без отбора
python -m scenarios.verification --omega      # с дрейфом Omega из config.py
```

Результаты: `verification_outputs/` (`verification.png`, `summary.json`).

Что сравнивается:
- средняя концентрация в синапсе и время её спада - Clements et al., 1992 (~1 мМ, τ ~1 мс);
- длина спада пика концентрации λ - Matthews et al., 2022 (iGluSnFR, λ ≈ 1.2 мкм);
- радиус, до которого превышен порог внесинаптических NMDA-R (~0.25 мкМ, Herman et al., 2011).

Новые параметры в `config.py` (блок «Абсолютные единицы»): `molecules_per_release`,
`extracellular_volume_fraction` (α), `Km_uM`, `Vmax_pm_uM_per_us`, `Vmax_cleft_uM_per_us`.
Перевод единиц: `utils/units.py`. Тесты: `python -m unittest tests.test_units tests.test_validation`.
