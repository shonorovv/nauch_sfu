# Инструкция по работе с проектом

Численная модель диффузии частицы в синаптической щели.  
Уравнение Фоккера-Планка, неявная разностная схема, радиальная геометрия.

---

## Структура проекта

```
diplom/
├── config.py                  ← ВСЕ параметры модели (менять здесь)
├── backend.py                 ← автовыбор GPU (CuPy) или CPU (NumPy)
├── main.py                    ← точка входа, запускать отсюда
├── ИНСТРУКЦИЯ.md              ← этот файл
│
├── solver/
│   ├── geometry.py            ← сетка, меры объёма оболочек (dr, dV)
│   └── fp_solver.py           ← решатель уравнения ФП (неявная схема)
│
├── physics/
│   ├── transport.py           ← профили D(r) и Omega(r): sigmoid/poly переходы
│   └── pulses.py              ← гауссовы импульсы, расписание, триггеры
│
├── analysis/
│   ├── entropy.py             ← Шэнноновская энтропия, локальная энтропия оболочек
│   ├── information.py         ← KL-дивергенция, взаимная информация, редкие события
│   ├── inversion.py           ← детекция инверсий пика вероятности
│   └── scenarios.py           ← сборка сценариев, запуск одного/нескольких вариантов
│
├── visualization/
│   ├── plots.py               ← статические графики: p(r,t), сигма, энтропия
│   ├── animations.py          ← анимации: ломтики, временные серии, тепловые карты
│   └── realtime.py            ← live-отрисовка во время счёта
│
├── export/
│   ├── data.py                ← сохранение npz/csv/json
│   ├── figures.py             ← автоматический экспорт всех графиков
│   └── reports.py             ← консольные отчёты и сводный txt-файл
│
└── utils/
    ├── helpers.py             ← мелкие утилиты (sanitize_window и т.д.)
    └── formatting.py          ← форматирование вывода, сохранение фигур
```

## Что менять в config.py

### Физика диффузии

| Параметр | Описание | Типичные значения |
|---|---|---|
| `D_cleft` | Коэффициент диффузии внутри синапса, нм²/мкс | 400 |
| `D_pm` | Коэффициент диффузии снаружи | 150 |
| `D_delta_override` | Если задать число, `D_pm = D_cleft - это_число` | None |
| `a` | Внутренняя граница синапса, нм | 200 |
| `b` | Внешняя граница синапса, нм | 400 |
| `D_transition_kind` | Форма перехода D между зонами | `"sigmoid"` или `"poly"` |
| `D_transition_steepness` | Крутизна перехода (больше = резче) | 5–30 |

### Дрейф (Omega)

| Параметр | Описание |
|---|---|
| `Omega_cleft` | Дрейф внутри синапса (0 = нет дрейфа) |
| `Omega_pm` | Дрейф снаружи. По умолчанию `3 * Omega_cleft` |
| `Omega_transition_kind` | Форма перехода: `"poly"` или `"sigmoid"` |

Чтобы полностью отключить дрейф:
```python
Omega_cleft = 0.0
Omega_pm = 0.0
```

### Сетка и время

| Параметр | Описание |
|---|---|
| `max_r` | Максимальный радиус сетки, нм |
| `dr` | Шаг по пространству, нм. Меньше = точнее, но дольше |
| `dt` | Шаг по времени, мкс. Схема неявная, поэтому крупный dt допустим |
| `base_t_max` | Полное время расчёта, мкс |
| `time_divider` | Делитель времени (t_max = base_t_max / time_divider) |

Для быстрой проверки: `dr = 1.0`, `dt = 0.5`, `base_t_max = 1000.0`  
Для точного расчёта: `dr = 0.05`, `dt = 0.05`, `base_t_max = 20000.0`

### Импульсы

```python
num_pulses = 50         # количество. 0 = без импульсов
pulse_amount = 5.0      # доля вероятности на импульс
pulse_sigma_nm = 35.0   # ширина гауссова профиля, нм
pulse_r_window = (0.0, 151.0)   # радиальная область применения
pulse_max_frequency_hz = 100.0  # максимальная частота

pulse_trigger_mode = "schedule"  # "schedule" - равномерно по времени
                                 # "on_decay"  - при спаде плотности
```

Чтобы запустить без импульсов: `num_pulses = 0`

### Граничные условия и геометрия

```python
outer_boundary_mode = "dirichlet"  # поглощение на внешней границе
# outer_boundary_mode = "no_flux"  # отражение

geometry_mode = "spherical"        # сферическая симметрия
# geometry_mode = "cylindrical"    # цилиндрическая симметрия
```

### GPU и память

```python
use_gpu = True              # True = GPU (CuPy), False = CPU (NumPy/scipy)
max_saved_frames = 2000     # максимум кадров p(r,t) в памяти
```

`max_saved_frames` прореживает историю: при 200 000 шагах и 2000 кадрах
сохраняется каждый 100-й шаг (~5 мкс интервал). Для анализа достаточно.

### Вывод и экспорт

```python
export_figures = True       # сохранять графики в png
export_data = True          # сохранять данные в npz/csv/json
enable_animation = False    # показывать интерактивную анимацию после счёта
realtime_modeling = True    # live-отрисовка во время счёта
output_dir = Path("результаты_моделирования")  # куда сохранять
```

и сравнивает их между собой. Параметры сценариев жёстко прописаны внутри него.

## GPU-ускорение через CuPy

Научный руководитель рекомендовал перевести вычисления на CUDA.  
Инструкция по переводу находится в файле **`CUDA_ИНСТРУКЦИЯ.md`**.

Краткая суть: заменить `import numpy as np` → `import cupy as cp`  
и `from scipy.sparse import ...` → `from cupyx.scipy.sparse import ...`  
в файлах `solver/fp_solver.py` и `physics/transport.py`.

## Типичные проблемы

**`numpy._core._exceptions._ArrayMemoryError: Unable to allocate ... GiB`**  
→ Памяти не хватает для хранения всей истории p(r,t).  
→ Уменьши `max_saved_frames` в `config.py` (например, до 500) или включи GPU (`use_gpu = True`).  
→ По умолчанию `max_saved_frames = 2000` хранит ~320 МБ вместо 32 ГБ.

**Счёт идёт очень долго**  
→ Увеличь `dr` (например, с 0.05 до 0.5) и `dt` (с 0.05 до 0.5).  
→ Уменьши `base_t_max` для тестового прогона.  
→ Установи CuPy и включи `use_gpu = True` в `config.py` (инструкция в `CUDA_ИНСТРУКЦИЯ.md`).

**`ModuleNotFoundError: No module named 'config'`**  
→ Запускай из папки `diplom/`, не из родительской:  
```powershell
cd D:\sfu_code\nauch\diplom
python main.py
```

**`ModuleNotFoundError: No module named 'scipy'`**  
```powershell
pip install scipy numpy matplotlib
```

**Нет графиков / пустая папка результатов**  
→ Проверь `export_figures = True` в `config.py`.  
→ Проверь, что папка `результаты_моделирования/` создаётся без ошибок прав доступа.

**Окно анимации не открывается**  
→ `enable_animation = True` в `config.py`.  
→ Если запускаешь через ssh/WSL — matplotlib не может открыть окно, нужен X-сервер.
