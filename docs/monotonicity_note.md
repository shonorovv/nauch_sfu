# Монотонность радиального профиля концентрации: когда инверсия невозможна

Записка к этапу 3 ТЗ от 13.10.2026. Код проверки: `tests/test_inversion_physics.py`, детектор: `analysis/inversion_concentration.py`.

## 1. Постановка

Свободный глутамат c(r, t) ≥ 0 в доступной жидкости, r ∈ (0, R):

    c_t = (1/A)·(A·D·c_r)_r − R(c, r),        Ω = 0,

где A(r) = dV/dr > 0 - площадь поверхности переноса (геометрия Barbour 2001), D(r) > 0 - коэффициент диффузии, R(c, r) = Vmax(r)·c/(Km + c) - захват.

**Инверсия** - существование t и r₂ > r₁ с c(r₂, t) > c(r₁, t), то есть участка с c_r > 0. Смещение максимума профиля и рост числа молекул в наружных оболочках (объём оболочки растёт с r) инверсией концентрации не являются и считаются отдельно.

## 2. Утверждение

Пусть выполнено:

1. Ω ≡ 0;
2. D, A > 0, D ∈ C¹, V ∈ C² на (0, R] (у Barbour с квинтикой s(x) так и есть: s′ и s″ равны нулю на a и b);
3. R_r := ∂R/∂r при фиксированном c ≥ 0 неотрицательна, то есть захват не убывает с радиусом (у нас Vmax = 0 в щели, Vmax_pm > 0 снаружи, монотонный переход);
4. R_c := ∂R/∂c ≥ 0 и ограничена (для Михаэлиса-Ментен R_c = Vmax·Km/(Km + c)² ∈ [0, Vmax/Km]);
5. начальный профиль не возрастает: c_r(r, 0) ≤ 0 (гаусс в центре, в том числе обрезанный окном);
6. граничные условия: симметрия в центре (c_r(0, t) = 0) и снаружи либо c(R) = 0, либо нулевой поток;
7. нет других источников, кроме начального выброса в центре.

Тогда c_r(r, t) ≤ 0 при всех t > 0: профиль остаётся невозрастающим, инверсии нет.

## 3. Доказательство (схема с явными шагами)

Раскроем оператор: c_t = D·c_rr + β·c_r − R(c, r), где β = D′ + D·A′/A.

Продифференцируем по r и обозначим v = c_r:

    v_t = D·v_rr + (D′ + β)·v_r + (β′ − R_c)·v − R_r.                (*)

Граничные значения v: в центре v = 0 (симметрия). Снаружи при c(R) = 0 и c ≥ 0 внутри имеем v(R) ≤ 0; при нулевом потоке v(R) = 0. Начальное значение v(·, 0) ≤ 0.

Коэффициент при v ограничен сверху: β′ − R_c ≤ β′. Число sup β′ конечно, потому что:
- вблизи центра A ∝ r, отсюда (A′/A)′ = −1/r² < 0, то есть этот член ограничен сверху;
- на отрезке перехода β′ содержит V‴, у которой на a и b скачки, но она ограничена.

Возьмём Λ > sup β′ и положим w = e^(−Λt)·v. Тогда

    w_t = D·w_rr + (D′ + β)·w_r + (β′ − R_c − Λ)·w − e^(−Λt)·R_r,

где коэффициент при w строго отрицателен, а свободный член −e^(−Λt)·R_r ≤ 0 по условию 3. Если бы w впервые достигла положительного максимума во внутренней точке, там w_r = 0, w_rr ≤ 0, и правая часть строго отрицательна (при w > 0), то есть w_t < 0. Но в момент, когда максимум впервые достигнут, w_t ≥ 0. Противоречие. Стандартный слабый принцип максимума даёт w ≤ max(0, sup w(·, 0), sup на границе) = 0. Значит, v ≤ 0. Коэффициенты (*) ограничены и измеримы, скачки V‴ на a и b не мешают (принцип максимума в слабой форме). ∎

Замечание о резкой геометрии `cleft_disk` (единая подгонка 12.10). Там A(r) прыгает в точке a. Непрерывность потока A⁻·c_r⁻ = A⁺·c_r⁺ сохраняет знак c_r, так что вывод остаётся тем же.

## 4. Когда утверждение перестаёт работать (возможные механизмы инверсии)

| Нарушенное условие | Почему вывод теряется | Что это значит физически |
|---|---|---|
| Ω ≠ 0 | в (*) появляется член вида −(Ω′ + Ω·A′/A)′·c, его знак произвольный, и он не пропорционален v | дрейф наружу выносит глутамат из центра; это механизм курсовой. Физического источника такого дрейфа в нейропиле нет |
| R_r < 0 где-то | свободный член −R_r становится положительным | захват сильнее у щели, чем дальше (например, кольцо транспортёров на перисинаптической глии) |
| источники вне центра | нарушено условие 7 | соседние синапсы, многовезикулярный выброс с разнесёнными местами |
| немонотонный старт | нарушено условие 5 | остаточный глутамат от предыдущих выбросов |
| обратимое связывание (вторая переменная B) | система двух уравнений, скалярный принцип максимума к ней прямо не применяется | глутамат, связанный у края щели и отпущенный позже, может дать локальный рост; нужно проверять отдельно |
| неодномерная геометрия | радиальная запись теряет смысл | шипики, отростки глии, анизотропия |

## 5. Численные контроли (одна и та же решающая программа, Barbour a = 200, b = 400 нм, N = 3000)

| Контроль | Условия | Результат | Ожидание |
|---|---|---|---|
| 1 | D = 320 всюду, без захвата и дрейфа | наибольший рост c по r: 0 | нет инверсии |
| 2 | D 10 → 320 и 760 → 320, геометрия Barbour | 0 | нет инверсии |
| 3 | + насыщаемый захват Vmax_pm = 0,01 мкМ/мкс | 0 | нет инверсии |
| 4 | курсовая: сфера, D 10/0,5, Ω 0,05/0,15 наружу | инверсия: ΔC = 14,6 мкМ, c(158 нм)/c(0) = 1,42, держится всю 1 мс | возможна |
| 4б | то же без дрейфа | 0 | нет инверсии |

Дискретная схема (неявная, конечные объёмы, upwind) сохраняет монотонность точно: положительных разностей соседних ячеек нет вообще (ноль, без допуска).

## 6. Вывод для работы

- Инверсия профиля в курсовой - следствие дрейфа наружу Ω > 0. Без дрейфа её нет ни при каких D(r), A(r) и неубывающем захвате.
- Подгонка к экспериментам (`docs/unified_model.md`) даёт дрейф обратного знака (внутрь). Данные механизм курсовой не поддерживают.
- Если искать инверсию дальше, нужны механизмы из таблицы п. 4, сформулированные заранее и проверяемые: неоднородный захват (R_r < 0), обратимое связывание, неодномерная геометрия. Подбирать Ω или D в нефизиологическую область ради нужного графика нельзя.
- Отсутствие инверсии в базовом классе - самостоятельный результат: он показывает, какие механизмы вообще способны её создать. Содержательной может оказаться другая гипотеза: длительность воздействия глутамата на рецепторы при ослабленном захвате (п. 6.5 ТЗ).
