## 3. Единая подгонка в геометрии Barbour

Та же подгонка к 7 наборам (60 точек), что 12.10, теперь в `barbour_mixed` со схемой `split_implicit` и балансом массы:

| Вариант | χ² | AIC |
|---|---|---|
| прежняя геометрия `cleft_disk` (резкий переход), с дрейфом | 55,1 | 71,1 |
| Barbour, с дрейфом (`exploratory_drift`) | 54,4 | 70,4 |
| Barbour, Ω = 0 (`baseline_physical`) | 85,1 | 99,1 |
| прежняя геометрия, Ω = 0 | 92,1 | 106,1 |

Параметры Barbour с дрейфом почти совпали с прежними: D_cleft = 18,7, a = 250 нм (граница), N = 3010, s = −1,66, N анкейджинга 1,8·10⁵. Переход к гладкой геометрии результата не меняет; выводы `docs/unified_model.md` остаются в силе.

Без дрейфа гладкая геометрия описывает данные лучше резкой (χ² 85,1 против 92,1), а подогнанные параметры становятся ближе к литературе: a = 175 нм (у Barbour 180 нм), N = 6140 молекул (Budisantoso 2013: около 7000), D_cleft = 13,2 нм²/мкс. Дрейф по-прежнему улучшает AIC (70,4 против 99,1), то есть модели без дрейфа не хватает механизма; кандидат - быстрое связывание с транспортёрами (п. 4). Захват в обоих вариантах уходит к нижней границе, проверка Diamond 2005 (0,75 мс) не выполняется.

## 4. Что не сделано и почему

- Источник Vmax_pm = 3,6·10⁻³ мкМ/мкс и Km = 20 мкМ в `with_uptake` - рабочие оценки (пересчёт константы глии Lotter 2021). Первоисточник EAAT для конкретного препарата не подобран (п. 2.3 ТЗ).
- Кинетический захват со связыванием (вторая переменная B) - следующий этап; он нужен и для AMPA-данных Matthews с TBOA.
- `analysis/excitotoxicity.py` и `analysis/entropy.py` не переименованы и не переписаны (P0.5, P1.4): в ТЗ они вне сдачи этапов 0-2. До их правки эти графики в физической проверке не используются.
- Исторические сценарии (`scenarios/supervisor_revision.py`) заморожены и по-прежнему не передают параметры захвата в решатель (P1.3); новая ветка задаёт все члены явно через `experiments/configs.py`.
- Расчёты на GPU для сравнения с CPU не повторялись.
