Ошибки 1σ из тех же отчётов: радиус щели 174,7 нм при ошибке 158,4 нм (Ω = 0) и 250,0 нм при ошибке 635,1 нм (с дрейфом); число молекул 3010,5 при ошибке 9336,6 (с дрейфом); `Vmax_pm` в обоих вариантах упирается в нижнюю границу, ошибка 12,3 и 2,0 порядка в log10. Одновременная подгонка геометрии, N, D, Vmax и сенсора по 60 точкам - ровно то, от чего предостерегает п. 7.
3. Проверка по Diamond 2005 (время очистки 0,75 мс) в обоих вариантах не выполняется: в отчётах `uptake_tau_ms_vs_Diamond2005_0.75 = inf`.

## 5. Что не сделано и почему

| Что | Причина |
|---|---|
| Эксайтотоксичность как физический результат | вне сдачи ТЗ; нужны кинетика рецепторов и Ca2+ |
| Кинетический захват со связыванием (вторая переменная B) | следующий этап; без него не воспроизводится AMPA с TBOA |
| Источники `Vmax_pm`, `Km` | рабочие оценки, первоисточник EAAT для препарата не подобран (п. 2.3 ТЗ) |

| Сравнение CPU и GPU | расчёты на GPU не запускались |
| Этап 5 (мозжечок, Power & Empson 2014) | по ТЗ только после этапов 1-4; статьи Power & Empson в `refs/` нет |
| Таблица переноса параметров между исследованиями, анализ идентифицируемости | не начаты |
| `.gitignore` | `validation_data/*.xlsx` попадает под правило `*.xlsx`; чтобы файлы сохранялись в репозитории, нужна строка-исключение. Не менял без вашего подтверждения |
